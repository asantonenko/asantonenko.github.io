3.    Пустой оператор

Синтаксис: ;

Пустой оператор состоит только из точки с запятой. При выполнении этого оператора ничего не происходит. Он обычно используется в следующих случаях:

  • в операторах do, for, while, if в местах, если оператор не нужен, но по синтаксису требуется хотя бы один оператор;

  • при необходимости пометить фигурную скобку.

Синтаксис языка Си требует, чтобы после метки обязательно следовал оператор. Фигурная же скобка оператором не является. Поэтому, если надо передать управление на фигурную скобку, необходимо использовать пустой оператор.

Кроме того, пустой оператор появляется, если поставить лишнюю точку с запятой.

Примеры:

{x=1;y++;};i--;
//        ↑ пустой оператор

Здесь пустой оператор появился, так как поставлена лишняя точка с запятой (в конце составного оператора она не нужна). Таких случаев появления пустого оператора желательно избегать - для этого просто помните, когда нужна точка с запятой, а когда нет.

{
	if (x==0) goto exit_from_block;

	//выполняем некоторые действия

	exit_from_block: ;

}

Перед закрывающей фигурной скобкой стоит пустой оператор, помеченный меткой exit_from_block. Другое дело, что такой стиль (и, вообще, использование оператора goto) очень нежелателен в современных программах. Используйте операторы break, continue, return или генерацию исключительных ситуаций оператором throw взамен. Например, если этот фрагмент был в цикле for и нужно пропустить (не обрабатывать) значение x, равное нулю, то лучше использовать оператор continue:

for (int x = -15; x <= 15; x++)
{
	if (x==0) continue; //пропускаем значение равное 0

	//выполняем некоторые действия для x от -15 до -1 и от 1 до 15
}

Пусть нам необходимо найти в некотором массиве arr значение равное value.  

int index = 0;
for (;index < std::size(arr) && arr[index] != value; index++);

В данном случае внутри оператора for не понадобилось ни одного оператора. Мы просто увеличивали значение переменной index, пока выполнено два условия: мы находимся внутри массива (index < std::size(arr)) и элемент с заданным индексом нам не подходит (arr[index] != value). В конце значение index переменной равно или индексу найденного элемента, равного value или размеру массива, равному std::size(arr), если элемент не найден. Так как переменная index нужна после цикла, то объявить её внутри цикла нельзя. Подробнее см. описание оператора for, а также урок Использование цикла for для контейнеров.

В целом, пустой оператор не так часто нужен в программе.
