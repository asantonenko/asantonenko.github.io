Взаємовиключні умови

Дуже часто в програмі доводиться використовувати взаємовиключні умови. Розглянемо приклад розв'язання квадратного рівняння. Після обчислення дискримінанта у нас є три варіанти: дискримінант більший за 0 (два корені), дискримінант дорівнює 0 (один корінь) і дискримінант менший за 0 (немає коренів). Ці умови взаємовиключні, тобто ми спочатку перевіряємо першу умову, якщо вона не виконана, перевіряємо другу тощо. Таким чином, кожен наступний if виявляється вкладеним у попередній.

Якщо спробувати записати загальну структуру вкладених операторів if строго за правилами, розставляючи всі фігурні дужки та відступи, вийде так:

double D = b * b - 4 * a * c;

if (D > 0)
{
	cout <<"Два корені!" <<endl;
}
else
{
	if (D == 0)
	{
		cout <<"Один корінь!" <<endl;
	}
	else 
	{
		if (D < 0)
		{
			cout <<"Коренів немає!" <<endl;
		}
	}
}

Така структура фігурних дужок і відступів дуже громіздка, ми отримуємо драбинку з операторів із дедалі більшими відступами. Зазвичай замість цього умовно об'єднують два ключові слова else та if в одну конструкцію else if, не ставлячи цих необов'язкових дужок. Крім того, останній оператор if взагалі можна не записувати, оскільки якщо не виконані перші дві умови, то автоматично виконана третя. Отримуємо таку структуру:

double D = b * b - 4 * a * c;

if (D > 0)
{
	cout <<"Два корені!" <<endl;
}
else if (D == 0)
{
	cout <<"Один корінь!" <<endl;
}
else 
{
	cout <<"Коренів немає!" <<endl;
}

Цей варіант виглядає набагато компактніше та простіше за попередній.

Наведемо також повний текст програми розв'язання квадратного рівняння:

#include <iostream>
#include <cmath>

using namespace std;

int main() 
{
	double a, b, c; //коефіцієнти квадратного рівняння
	
	cout <<"Введіть три коефіцієнти рівняння (a b c):" <<endl;
	
	cin  >>a >>b >>c;
	
	cout <<"Рівняння має вигляд: " <<a <<"*x*x + " <<b<<"*x + " <<c <<" = 0" <<endl;
	
	double D = b*b - 4*a*c; //Обчислюємо дискримінант
	
	if (a==0) //Це взагалі не квадратне рівняння
	{
		cout <<"Це рівняння не є квадратним! "<<endl;
	}
	else if (D>0) //Якщо дискримінант більший за нуль, то є два різні дійсні корені 
	{
		double x1 = (-b+sqrt(D)) / (2*a);
		double x2 = (-b-sqrt(D)) / (2*a);
		cout <<"Рівняння має два різні дійсні корені: " <<endl;
		cout <<"x1= " <<x1 <<"  x2= " <<x2 <<endl;
	}
	else if (D==0)
	{
		double x12 = -b/(2*a);
		cout <<"Рівняння має один дійсний корінь: " <<endl;
		cout <<"x12= " <<x12 <<endl;
	}
	else
	{
		cout <<"Рівняння не має дійсних розв'язків!" <<endl;
	}
	
	return 0;
}

Зверніть увагу, в яких місцях оголошено змінні в програмі. Нагадаємо, що в мові С++ використовуються такі правила гарного стилю:

  1. Змінні потрібно робити настільки локальними, наскільки це можливо (без втрати сенсу чи ефективності роботи). Наприклад, змінні x1 і x2 оголошені лише всередині оператора if (D>0), тому вони не існують в інших гілках або поза if.
  2. Змінні бажано оголошувати в міру необхідності - якомога ближче до місця використання. Нагадаємо, що в старих версіях мови Сі (С89) змінні потрібно було оголошувати на початку блоку. Тому в тих, хто переходить зі старих версій мови C, або мови Pascal, або кого навчили по-старому, може з'явитися вельми шкідлива звичка оголошувати всі змінні на початку. У сучасному C++ це зовсім не потрібно, більше того, це вважається поганим стилем! Тому спочатку ми оголосили лише змінні a, b, c для вхідних даних - коефіцієнтів квадратного рівняння, а от змінну D для дискримінанта оголосили лише після введення значень змінних a, b і c.
  3. Бажано, по можливості, оголошуючи змінну, одразу ж присвоювати їй потрібне значення. У програмі так відбувається зі змінними D, x1, x2, x12. Лише змінним a, b, c не присвоюється початкове значення - але тільки тому, що вони зчитуються з клавіатури і цю дію не можна (без додаткових зусиль - створення допоміжних функцій або використання складних конструкцій) записати у вигляді ініціалізації змінної.
