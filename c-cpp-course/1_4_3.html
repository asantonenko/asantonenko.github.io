Але все ж, просунутий калькулятор уміє виконувати не лише 4 арифметичні операції, а й обчислювати значення різних функцій. Спробуймо обчислити значення функцій для деякого аргументу.

Щоб запустити деяку функцію в мовах C і C++, потрібно вказати ім’я функції та в дужках її аргументи або параметри. Наприклад, розглянемо зіставлення деяких математичних виразів з їхніми еквівалентами в C/C++:

Математичний вираз Вираз мовами C/C++
\(2x\) 2*x
\({x+y \over xy}\) (x+y)/(x*y)
\(\sqrt{x}\) sqrt(x)
\(x ^ y\) pow(x,y)

Функція pow має два параметри, які відокремлюються один від одного комою.

Отже, напишемо калькулятор, який обчислюватиме функції одного аргументу. Для початку введемо з клавіатури аргумент функції, який назвемо x:

#include <iostream>  //заголовний файл для введення та виведення

using namespace std; //використовуємо простір std

int main()    //основна функція програми
{             //початок основного блоку                 
    double x; //Аргумент (параметр) функцій  

    cout << "Введіть аргумент функцій (дійсне число):" << endl; //Виводимо підказку
    cin >> x;                                                   //Вводимо значення з клавіатури

    //Тут буде решта програми

    return 0;     //повідомляємо, що програма успішно завершила роботу
}                 //кінець основного блоку

Тепер додамо виведення обчислених значень різних функцій:  

#include <iostream>
#include <cmath>     //заголовний файл для математичних функцій

using namespace std; 

int main()    
{                           
    double x; 
    cout << "Введіть аргумент функцій (дійсне число):" << endl; 
    cin >> x;                                                         
    
    cout << "Квадрат              " << x << " = " << x*x      << endl;  //Друкуємо квадрат x
    cout << "Куб                  " << x << " = " << pow(x,3) << endl;  //Друкуємо куб x
    cout << "Квадратний корінь    " << x << " = " << sqrt(x)  << endl;  //Друкуємо квадратний корінь x
    cout << "Експонента           " << x << " = " << exp(x)   << endl;  //Друкуємо експоненту x
    cout << "Натуральний логарифм " << x << " = " << log(x)   << endl;  //Друкуємо натуральний логарифм x
    cout << "Десятковий логарифм  " << x << " = " << log10(x) << endl;  //Друкуємо десятковий логарифм x    
    cout << "Синус                " << x << " = " << sin(x)   << endl;  //Друкуємо синус x
    cout << "Косинус              " << x << " = " << cos(x)   << endl;  //Друкуємо косинус x
    cout << "Тангенс              " << x << " = " << tan(x)   << endl;  //Друкуємо тангенс x
    cout << "Арксинус             " << x << " = " << asin(x)  << endl;  //Друкуємо арксинус x
    cout << "Арккосинус           " << x << " = " << acos(x)  << endl;  //Друкуємо арккосинус x
    cout << "Арктангенс           " << x << " = " << atan(x)  << endl;  //Друкуємо арктангенс x

    return 0;     
}

Нагадаю, що в коді вище прокоментовано лише нові рядки. Для використання математичних функцій потрібно підключити заголовний файл cmath (або заголовний файл math.h у мові C). Як бачите, стандартних функцій для квадрата й куба в мовах C/C++ немає, але можна записати квадрат і куб через функцію pow як другий і третій степінь: pow(x,2) і pow(x,3), або просто через множення як x*x і x*x*x. Також зазначу, що в мовах C/C++ для деяких функцій використовуються позначення, відмінні від загальноприйнятих у математиці (творці мови C погано пам’ятали стандартні математичні позначення?). До речі, я не став створювати окрему змінну для зберігання результатів обчислення функцій — інакше в програмі було б дуже багато змінних. Замість цього я просто одразу вивів обчислені значення в потік виведення cout.
