Коротка альтернатива оператору if — тернарна операція

Часто оператор if можна компактніше записати у вигляді тернарної операції. Це можна зробити, якщо від умови залежить не те, які дії потрібно виконати, а те, яке значення буде підставлено в певне місце програми.

Наприклад, нехай нам потрібно знайти модуль числа x, і ми чомусь не хочемо використовувати стандартну функцію abs. Тоді замість оператора if:

if (x >= 0)
{ 
	y = x;
}
else
{
	y = -x;
}

або трохи коротшої форми

if (x >= 0) y = x; else y = -x;

краще записати 

y = (x >= 0) ? x : -x;

Залежно від істинності логічного виразу (x >= 0) значення виразу (x >= 0) ? x : -x дорівнюватиме або x, або -x. До речі, дужки тут не обов'язкові, і можна записати

y = x >= 0 ? x : -x;

Наведемо ще кілька прикладів, де доречне таке скорочення:

Замість

if (x % 2 == 0)
{
	cout <<"Число " <<x <<" парне!" <<endl;
}
else
{
	cout <<"Число " <<x <<" непарне!" <<endl;
}

доречно записати

cout <<"Число " <<x <<" " <<(x % 2 == 0?"парне":"непарне") <<"!" <<endl;

У другому варіанті спочатку виводиться стала частина "Число ", потім змінна частина — ціле число x, потім стала частина — пробіл, далі знову змінна частина — слово "парне" або слово "непарне", потім знову стала частина — знак оклику, а тоді маніпулятор endl.

Мовою C ми використовуватимемо форматований вивід за допомогою стандартної функції printf:

printf("Число %d %s!\n", x, x % 2 == 0?"парне":"непарне");

і це той випадок, коли варіант виводу мовою C навіть легше читається — замість %d буде підставлено ціле число x, а замість %s — рядок, що є результатом виразу x % 2 == 0?"парне":"непарне".

Але виконати заміну if на тернарну операцію в такому стилі можна не завжди. Наприклад, нехай нам потрібно вивести цілу відповідь answer, але спеціальне значення answer, що дорівнює -1, означає, що відповіді немає. Тоді можна спробувати такий спосіб:

cout <<"Answer = " <<(answer == -1 ? "not exists" : answer) <<endl;

Залежно від значення answer виводимо або значення answer, або спеціальне повідомлення "not exists" (не існує). Але так не можна — ми отримаємо помилку компіляції. Чому? Розглянемо вираз (answer == -1 ? "not exists" : answer). Якого він типу? Виходить, що тип виразу залежить від значення змінної answer — або число, або рядок. Хоча ми можемо вивести і число, і рядок за допомогою потоку cout, так записати не можна, оскільки будь-який вираз у мовах C/C++ повинен мати чітко визначений компілятором формальний тип, який не може залежати від значень якихось змінних, від введення користувача, результату роботи функцій тощо. Тому у виразі (умова?значення-1:значення-2) підвирази значення-1 і значення-2 повинні мати однаковий тип (або їх можна привести до одного типу за допомогою неявного приведення типів).
