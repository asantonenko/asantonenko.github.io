2. Складений оператор

Синтаксис: (C89)

{

[oголошення;] ... [oголошення;]

оператор; [оператор;] ... [оператор;]

}

Синтаксис: (C99 і C++)

{

[оператор або oголошення;]

...

[оператор або oголошення;]

}

Складений оператор являє собою кілька операторів і оголошень, укладених у фігурні дужки. Зауважимо, що на відміну від Паскаля після складеного оператора крапка з комою не ставиться. Але перед закривною фігурною дужкою крапка з комою ставиться.

Виконання складеного оператора полягає в послідовному виконанні операторів, що його становлять. Оголошення змінних, описані в складеному операторі, мають іти перед операторами в старій версії мови C — C89 і в будь-якому місці (тобто, можливо, між операторами) у нових версіях мови Сі (починаючи з C99) та в мові C++. Ці оголошення є локальними в межах складеного оператора (тобто змінні не існують за межами складеного оператора).

Складений оператор зазвичай використовується, коли за синтаксисом мови Сі має бути один оператор (наприклад в операторах if, while, do while, for), а необхідно виконати кілька дій.

Приклад 1:

Код мовою Сі:

int i,j;

...

{ int tmp=i; i=j; j=tmp; }

Код мовою Паскаль:

var i,j,tmp:integer;

...

begin tmp:=i; i:=j; j:=tmp end;

Міняє значення змінних i і j місцями. Порівняйте розташування крапок з комою. Також зауважимо, що тимчасову змінну tmp, яку використано в обміні змінних i і j місцями, у мовах C/C++ вдається оголосити всередині складеного оператора, на відміну від мови Pascal.

Зауважимо, що наведений код правильний, але погано оформлений — складений оператор записано в один рядок. Якщо у Вас немає причини для жорсткої економії кількості рядків, не робіть так, а оформлюйте код, наприклад, так:

int i, j;

...

{
    int tmp = i; 
    i = j; 
    j = tmp; 
}

Зверніть увагу також на додаткову розстановку пробілів, яка підвищує зручність читання.

Примітка: У мові C++ (але не в мові Сі) існує стандартна функція std::swap (заголовковий файл <utility>), яка міняє значення змінних місцями, тому для C++ краще скористатися нею:

int i, j;

...

std::swap(i, j);

Приклад 2: Припустимо, що деякі змінні існували до складеного оператора, але потім ми оголосили змінні з такими самими іменами всередині складеного оператора.

int i = 1, x = 2, j = 2;
{
    int i; /* у цьому місці значення нової змінної i не визначене */
    double x = 0.1; 
    int q = 1;
    i = j + 1; /* внутрішня, але не зовнішня змінна i отримує значення 3 */
    j = 7; /* оскільки немає локальної всередині блоку змінної j, присвоюємо значення зовнішній змінній */
    cout <<"i=" <<i <<" x=" <<x <<" q=" <<q <<" j=" <<j <<endl;
    /* i=3 x=0.1 q=1 j=7*/
}
/* i=1 x=2 j=7 q не існує*/

Зазначимо, що змінні i, x є локальними в складеному операторі, тобто вони жодним чином не пов'язані зі змінними i, x, оголошеними до складеного оператора. Коли ми присвоюємо змінній i значення j+1, то присвоюємо його саме внутрішній змінній, оголошеній у складеному операторі. З іншого боку, присвоюючи нове значення j, що дорівнює 7, ми змінюємо зовнішню стосовно складеного оператора змінну. Змінні i, x, q буде знищено після виконання складеного оператора. Тому після складеного оператора знову будуть доступні початкові цілі змінні i і x зі значеннями 1 і 2 (вони не змінювали своїх значень).

Також зауважу, що цей приклад досить штучний і безглуздий, у реальних програмах слід, по можливості, уникати такого затінення одних локальних змінних іншими, ще більш локальними.
