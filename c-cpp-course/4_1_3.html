2.    Составной оператор

Синтаксис: (C89)

{

    [oбъявление;] ... [oбъявление;]

    оператор; [оператор;] ... [оператор;]

}

Синтаксис: (C99 и C++)

{

    [оператор или oбъявление;]

    ...

    [оператор или oбъявление;]

}

Составной оператор представляет собой несколько операторов и объявлений, заключенных в фигурные скобки. Заметим, что в отличие от Паскаля после составного оператора точка с запятой не ставится. Но перед закрывающей фигурной скобкой точка с запятой ставится.

Выполнение составного оператора заключается в последовательном выполнении составляющих его операторов. Объявления переменных, описанные в составном операторе, должны идти до операторов в старой версии языка C - C89 и в любом месте (т.е., возможно, между операторами) в новых версиях языка Си (начиная с C99) и языке C++. Эти объявления являются локальными в пределах составного оператора (т.е. переменные не существуют за пределами составного оператора).

Составной оператор обычно используется, когда по синтаксису языка Си должен быть один оператор (например в операторах if, while, do while, for), а необходимо сделать несколько действий.

Пример 1:

Код на Си:

int i,j;

...

{ int tmp=i; i=j; j=tmp; }

Код на Паскале:

var i,j,tmp:integer;

...

begin tmp:=i; i:=j; j:=tmp end;

Меняет значения переменных i и j местами. Сравните расположение точек с запятой. Также заметим, что временную переменную tmp, используемую в обмене переменных i и j местами в языках C/C++ удаётся объявить внутри составного оператора, в отличии от языка Pascal.

Заметим, что приведенный код правильный, но плохо оформленный - составной оператор записан в одну строку. Если у Вас нет причины для жесткой экономии количества строк, не делайте так, а оформляйте код, например, так:

int i, j;

...

{
    int tmp = i; 
    i = j; 
    j = tmp; 
}

Обратите внимание также на дополнительную расстановку пробелов, которая повышает удобство чтения.

Примечание: В языке C++ (но не языке Си) существует стандартная функция swap, которая меняет значения переменных местами, поэтому для C++ лучше воспользоваться ей:

int i, j;

...

swap(i, j);

Пример 2: Предположим, что некоторые переменные существовали до составного оператора, но затем мы объявили переменные с такими же именами внутри составного оператора.

int i = 1, x = 2, j = 2;
{
    int i; /* в данном месте значение новой переменной i не определено */
    double x = 0.1; 
    int q = 1;
    i = j + 1; /* внутренняя, но не внешняя переменная i получает значение 3 */
    j = 7; /* так как нет локальной внутри блока переменной j, присваиваем значение внешней переменной */
    cout <<"i=" <<i <<" x=" <<x <<" q=" <<q <<" j=" <<j <<endl;
    /* i=3 x=0.1 q=1 j=7*/
}
/* i=1 x=2 j=7 q не существует*/

Отметим, что переменные i, x являются локальными в составном операторе, т.е. они никоим образом не связаны с переменными i, x объявленными до составного оператора. Когда мы присваиваем переменной i значение j+1, то мы присваиваем его именно внутренней переменной, объявленной в составном операторе. С другой стороны, присваивая новое значение j равное 7, мы меняем внешнюю по отношению к составному оператору переменную.  Переменные i, x, q будут уничтожены после выполнения составного оператора. Поэтому после составного оператора будут опять доступны изначальные целые переменные i и x, со значениями 1 и 2 (они не меняли свои значения).

Также замечу, что данный пример достаточно синтетический и бессмысленный, в реальных программах следует, по возможности, избегать такого затенения одних локальных переменных другими еще более локальными.
