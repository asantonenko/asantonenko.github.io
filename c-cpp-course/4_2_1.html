4. Умовний оператор if

Синтаксис:

if (вираз) оператор-1; [else оператор-2;]

Виконання оператора if починається з обчислення виразу.

Далі виконання здійснюється за такою схемою:

  • якщо вираз істинний (тобто відмінний від 0), то виконується оператор-1.

  • якщо вираз хибний (тобто дорівнює 0), то виконується оператор-2.

  • якщо вираз хибний і оператор-2 відсутній (у квадратні дужки взято необов'язкову конструкцію), то виконується наступний за if оператор.

Після виконання оператора if керування передається на наступний оператор програми, якщо послідовність виконання операторів програми не буде примусово порушена використанням операторів переходу.

Оператор if дозволяє створювати розгалужені алгоритми, які передбачають вибір маршруту виконання програми залежно від істинності чи хибності деяких умов.

Вираз часто містить операції відношення (порівняння) (==, >, < тощо) і логічні операції (||, &&, !). Частою помилкою є використання присвоєння (=) замість порівняння (==).

Якщо потрібно виконати не один, а кілька операторів при виконанні умови (або, навпаки, в блоці else, коли умову не виконано) - необхідно використовувати складений оператор.

Приклад:

if (x==0) i++; else {i--;x=-x;} x+=10;

Якщо x дорівнює нулю, то виконується оператор-вираз i++, інакше виконується складений оператор {i--;x=-x;}. У будь-якому разі після цього виконується оператор x+=10.

Наведений вище приклад абсолютно правильний з точки зору синтаксису, але дуже погано оформлений - в один рядок. Краще оформити його так:

if (x==0) 
{
    i++;
}
else 
{
    i--;
    x=-x;
}
x+=10;

Порада професійного програмування: Зверніть увагу - усередині оператора if прийнято обов'язково використовувати складені оператори, тобто фігурні дужки, навіть якщо в цих фігурних дужках потрібен лише один оператор. Це мінімізує ймовірність помилок.

Умову (x!=0) можна коротко записати як (x), а умову (x==0) – як (!x). Але не робіть так, якщо x є за змістом числом, а не логічним значенням, інакше це збиває програміста з пантелику.

З іншого боку, якщо значення деякої змінної flag є логічним (або змінна типу bool, або змінна цілого типу в мові Сі, але така, що позначає логічне значення) - то не пишіть if (flag == true) або if (flag == 1) або if (flag != 0) - такий запис видасть у Вас новачка в програмуванні, пишіть if (flag), так само замість if (flag == false) або if (flag == 0) пишіть просто if (!flag).

Відмінності оператора if в C/C++ від оператора if мови Паскаль:

  • вираз береться в дужки;

  • немає ключового слова then;

  • перед else ставиться крапка з комою, якщо оператор-1 не складений.

Оператор-1 і оператор-2 можуть бути будь-якими операторами, зокрема складеним оператором або операторами if. Останній випадок називається вкладеними операторами if. Щоб зробити програму читабельнішою, рекомендується групувати оператори та конструкції у вкладених операторах if, використовуючи фігурні дужки. Якщо ж фігурні дужки опущено, то компілятор пов'язує кожне ключове слово else з найближчим if, для якого немає else. Крім того, оператори всередині if, як і всередині інших складних операторів, бажано виділяти відступами.

Приклад. Давайте спробуємо вивести повідомлення про помилку, якщо деяке значення value або надто велике (більше 10), або надто мале (менше 1).

if (value>=1)
    if (value>10) printf ("Error: value >10\n");
else printf ("Error: value <1\n");

Цей приклад працює неправильно, видаючи повідомлення "Error: value <1\n" для value від 1 до 10, оскільки else належить до другого if, а не до першого, як ми хотіли (ключове слово else зв'язується з найближчим if). Проблема виникла, тому що ми не поставили фігурні дужки. Тож це ще один аргумент ставити фігурні дужки в будь-якому разі. Розстановка відступу тут лише збиває програміста з пантелику, оскільки, на відміну від Python, відступ не впливає на процес компіляції. Явна розстановка всіх дужок, звісно ж, розв'язує проблему:

if (value>=1)
{
    if (value>10) 
    {
        printf ("Error: value >10\n");
    }
}
else
{
    printf ("Error: value <1\n");
}

Отже, тепер чітко видно, що оператор, який починається з if (value>10), лежить усередині оператора if (value>=1). Це якраз і є прикладом вкладених операторів if.

Втім, проблеми з коректністю написання цього оператора пов'язані з тим, що він написаний явно не оптимальним чином, набагато краще використовувати простішу еквівалентну конструкцію, яка вкаже на наявність помилки при виході значення за діапазон від 1 до 10:

if (value < 1)
{
    printf ("Error: value <1\n");
}
else if (value > 10) 
{
    printf ("Error: value >10\n");
}

Як Ви бачите, конструкція стала простішою - що зменшує ймовірність помилок. По можливості намагайтеся уникати великого ступеня вкладеності операторів if.
