4.3. Оператори циклу: while, do while, for

Оператор while

Синтаксис:

while (вираз) оператор;

Вираз тут називається умовою циклу, а оператор – тілом циклу. Оператор while називається циклом з передумовою, оскільки умова перевіряється до виконання тіла. Саме тому while зручно використовувати в ситуаціях, коли тіло циклу потенційно може не виконатися жодного разу - якщо умова виявиться хибною одразу.

Як вираз допускається використовувати будь-який вираз мови С++, а як тіло - будь-який оператор, зокрема порожній або складений. Тіло циклу може містити інший оператор while - це називається вкладеним циклом.

Схема виконання оператора while така:

  • обчислюється вираз;

  • якщо вираз хибний, виконання оператора while завершується, і виконується наступний за порядком оператор;

  • якщо вираз істинний, виконується тіло циклу, після чого процес повторюється з першого пункту.

Відмінності оператора while в C/C++ від однойменного оператора мови Паскаль:

  • умова циклу береться в дужки;

  • не використовується ключове слово do.

Порада професійного програмування: так само, як і для if, усередині while тіло циклу прийнято брати у фігурні дужки, навіть якщо воно складається з одного оператора. Це робить код однаково оформленим і зменшує ризик помилки, якщо пізніше в тіло доведеться додати ще один оператор.

Приклад. Порахуємо, скільки цифр у десятковому записі цілого числа.

#include <iostream>

using namespace std;

int main()
{
	int number;
	cout <<"Введіть ціле число: ";
	cin >>number;

	if (number < 0)
	{
		number = -number; //для від'ємних чисел рахуємо цифри модуля
	}

	int count = 0;

	if (number == 0) //особливий випадок: у числа 0 рівно одна цифра
	{
		count = 1;
	}

	while (number > 0)
	{
		count++;
		number /= 10;
	}

	cout <<"Кількість цифр: " <<count <<endl;

	return 0;
}

Ідея проста: поки в числі залишаються цифри (тобто поки number > 0), ми "відрізаємо" останню цифру цілочисельним діленням на 10 і збільшуємо лічильник count. Коли число стає рівним нулю, цифр більше не лишилося, і цикл завершується.

Тут якраз добре видно суть циклу з передумовою: якщо на вхід подати 0, умова number > 0 виявиться хибною одразу, і тіло циклу не виконається жодного разу. Тому довелося окремо обробити цей випадок до циклу - інакше для числа 0 програма видала б 0 цифр замість однієї.

Оператор do while

Синтаксис:

do оператор while (вираз);

Оператор циклу do while називається циклом з післяумовою і використовується тоді, коли тіло циклу треба виконати хоча б один раз - перш ніж уперше перевіряти умову. Схема виконання:

  • виконується тіло циклу (яке може бути складеним оператором);

  • обчислюється вираз;

  • якщо вираз хибний, виконання оператора do while завершується, і виконується наступний за порядком оператор; якщо вираз істинний, виконання продовжується з першого пункту.

Зверніть увагу: це не те саме, що repeat ... until мови Паскаль, хоча структурно вони дуже схожі. У Паскалі цикл repeat ... until завершується, коли умова стає істинною, а do while на С++, навпаки, продовжує виконуватися, поки умова істинна, і завершується, коли вона стає хибною. Якщо механічно переносити умову з Паскаля на С++ без інверсії - вийде цикл з точністю до навпаки.

Щоб перервати виконання циклу достроково, не чекаючи, поки умова сама стане хибною, можна використовувати оператор break.

Приклад. Гра "Вгадай число": комп'ютер загадує число, а гравець намагається його відгадати, отримуючи після кожної спроби підказку "забагато" або "замало".

#include <iostream>
#include <cstdlib>
#include <ctime>

using namespace std;

int main()
{
	const int MIN = 0;
	const int MAX = 999;

	srand (static_cast<unsigned int>(time(nullptr))); //ініціалізуємо генератор випадкових чисел

	int number = MIN + rand() % (MAX - MIN + 1); //число від MIN до MAX включно

	cout <<"Загадано число від " <<MIN <<" до " <<MAX <<"." <<endl;

	int tries = 0;
	int guess;

	do
	{
		cout <<"Ваша здогадка? ";
		cin >>guess;
		tries++;

		if (guess > number)
		{
			cout <<"Забагато!" <<endl;
		}
		else if (guess < number)
		{
			cout <<"Замало!" <<endl;
		}
	}
	while (guess != number);

	cout <<"Ви вгадали за " <<tries <<" спроб(и)." <<endl;

	return 0;
}

Цей приклад якраз чудово демонструє, навіщо потрібен саме do while, а не while: перш ніж перевіряти, чи вгадано число (тобто чи guess == number), гравець обов'язково має зробити хоча б одну спробу - інакше й перевіряти нічого.

Зауваження до вихідного варіанта коду:

  • Щоб узяти всі MAX-MIN+1 чисел діапазону [MIN;MAX], потрібно написати rand() % (MAX - MIN + 1) і потім додати MIN.

  • без виклику srand генератор псевдовипадкових чисел завжди стартує з одного й того самого стану, тому number буде однаковим при кожному запуску програми. Потрібно один раз ініціалізувати його, наприклад, поточним часом: srand(time(nullptr)) (для цього підключається заголовок <ctime>, а для rand/srand - <cstdlib>).

Оператор for

Синтаксис:

for (вираз-1; вираз-2; вираз-3) оператор;

Оператор for - найбільш загальний спосіб організації циклу в С++. Він відповідає циклу з лічильником for у Паскалі, але значно гнучкіший за нього.

  • Вираз-1 зазвичай використовується для встановлення початкового значення змінних, що керують циклом (ініціалізація).

  • Вираз-2 - це умова, за якої тіло циклу продовжує виконуватися.

  • Вираз-3 визначає, як змінюються керуючі змінні після кожного виконання тіла циклу (крок, або інкремент).

Схема виконання оператора for:

  • обчислюється вираз-1;

  • обчислюється вираз-2;

  • якщо значення виразу-2 відмінне від нуля (істина) - виконується тіло циклу, потім обчислюється вираз-3, і відбувається перехід до повторної перевірки виразу-2; якщо ж вираз-2 дорівнює нулю (хиба) - керування передається на оператор, що йде одразу за for.

Істотно, що перевірка умови завжди виконується на початку ітерації - перед тілом циклу. Це означає, що тіло циклу може не виконатися жодного разу, якщо вираз-2 одразу виявиться хибним. Таким чином, for, як і while, є циклом з передумовою.

Оператор for як скорочений запис while. Цикл

for (вираз-1; вираз-2; вираз-3)
    тіло;

за змістом еквівалентний такому запису через while:

вираз-1;
while (вираз-2)
{
    тіло;
    вираз-3;
}

Порада професійного програмування: ця еквівалентність точна лише доти, доки в тілі циклу немає оператора continue. У справжньому for оператор continue передає керування на вираз-3 (крок), а вже потім - на перевірку умови. А у "наївному" перекладі через while, наведеному вище, continue вискочить одразу з тіла while, минаючи вираз-3, - і це вже інша поведінка. Якщо потрібен справді точний еквівалент циклу for з continue всередині, вираз-3 доводиться дублювати перед кожним continue або обгортати тіло в додаткову конструкцію.

Класичний паскалівський оператор

for змінна := поч_знач to кін_знач do оператор;

який послідовно виконує оператор для значень змінної від початкового до кінцевого значення, на С++ записується так:

for (змінна = поч_знач; змінна <= кін_знач; змінна++)
    оператор;

Такий вигляд оператора використовується для циклів із заздалегідь відомою кількістю повторень.

Приклади:

for (i=1; i<=10; i++) printf ("%d ", i*i); //СІ: квадрати чисел від 1 до 10
for i:=1 to 10 do write (i*i,' ');
(*еквівалентний код на Паскалі*)
double i;
for (i=0; i<2*3.14; i+=3.14/16) printf ("%f ", sin(i)); //крок - дробове число
for (j=1; j<1000; j*=2) printf ("%d ", j); //крок - множення, а не додавання

Останні два приклади не мають прямих еквівалентів у класичному паскалівському for, оскільки там крок завжди ціле число, що додається до змінної, тоді як у С++ вираз-3 може бути будь-якою дією - множенням, діленням, викликом функції тощо.

Гнучкість оператора for також виявляється в тому, що вираз-1 і вираз-3 можуть містити одразу кілька виразів, перелічених через кому, - це дозволяє керувати циклом за допомогою не однієї, а кількох змінних одночасно.

Приклад. Розвернемо рядок символів "на місці", рухаючись назустріч двома індексами - з початку й з кінця:

char str[100];
//...

for (int top=0, bot=99; top<bot; top++, bot--)
{
    char temp = str[top];
    str[top] = str[bot];
    str[bot] = temp;
}

Тут для керування циклом використовуються одразу дві змінні, top і bot, - кожна з них на початку ініціалізується (у виразі-1) і на кожному кроці змінюється (у виразі-3), а умова виразу-2 перевіряє, що вони ще не зустрілися.

Іншим важливим варіантом використання for є нескінченний цикл. Для цього умовний вираз (вираз-2) залишають порожнім, а для виходу з циклу використовують додаткову умову всередині тіла та оператор break. Зазвичай у такому разі порожніми лишають і вираз-1, і вираз-3, і цикл набуває вигляду:

for (;;)
{
    //...
    if (/*умова завершення*/) break;
    //...
}

Аналог цього циклу через while: while (1) {...} або, що те саме й читається зрозуміліше, while (true) {...}.

Приклад - підсумовування чисел, що вводяться з клавіатури, доки не введуть 0:

int x, sum = 0;

for (;;)
{
    cin >>x;
    if (x == 0) break;
    sum += x;
    cout <<"Sum=" <<sum <<endl;
}

Оскільки за синтаксисом мови С++ оператор може бути порожнім, тіло оператора for також може бути порожнім (просто крапка з комою). Така форма іноді використовується для пошуку - весь "сенс" циклу тоді переноситься у вираз-2.

Приклад:

int i;
for (i=0; t[i]<10; i++) ;

Тут змінна циклу i після завершення циклу набуде значення індексу першого елемента масиву t, що не менший за 10 (перший елемент, для якого умова t[i]<10 перестає виконуватися).

По можливості не зловживайте порожнім тілом і виразами з побічними ефектами, розкиданими по всіх трьох частинах заголовка for, - такий код компактний, але важко читається. Якщо логіку циклу складно охопити одним поглядом на рядок for (...; ...; ...), часто краще явно виписати тіло циклу чи взагалі скористатися while.
