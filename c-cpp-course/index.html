Програмування мовами С та C++

Курс для студентів першого курсу ОНУ ім. І. І. Мечникова та всіх охочих

Про курс

Цей курс знайомить з основами програмування на мовах C С++. Основна увага приділяється мові C++, але розглядаються й особливості мови C.

Курс підійде як для новачків без досвіду програмування, так і для тих, хто вже знає інші мови (Pascal, Python, Java) та бажає освоїти С/C++.

Статус: у розробці

Для кого

Курс спеціально розроблений для:

  • Студентів першого курсу ОНУ ім. І. І. Мечникова
  • Початківців у програмуванні
  • Програмістів, що переходять з інших мов
  • Всіх, хто цікавиться низькорівневим програмуванням

Вимоги

Для успішного проходження курсу достатньо знань:

  • Базової шкільної математики
  • Арифметичних операцій
  • Основних понять алгебри
  • Елементарної геометрії

Досвід програмування не обов'язковий!
