5. Оператор switch

Синтаксис:

switch ( вираз )

{ [оголошення]

case константний-вираз1: [ список-операторів1 ]

[case константний-вираз2: [ список-операторів2 ]]

...

[ default: [ список-операторів ]]

}

Оператор switch призначений для організації вибору з множини різних варіантів.

Вираз, що йде за ключовим словом switch у круглих дужках, може бути будь-яким виразом, допустимим у мовах C/C++, значення якого має бути цілочисельним (цілого типу, зокрема char, bool або перелічуваного типу). Значення цього виразу є ключовим для вибору з кількох варіантів. Тіло оператора switch складається з кількох операторів, позначених ключовим словом case з подальшим константним виразом. Він не може містити звичайні змінні або виклики функцій. Зазвичай як константний вираз використовують цілі або символьні константи. Список операторів можна позначати кількома мітками case.

Усі константні вирази в операторі switch повинні бути унікальними (не повинні повторюватися). Окрім операторів, позначених ключовим словом case, може бути, але не більше одного, фрагмент, позначений ключовим словом default.

Список операторів може бути порожнім або містити один чи більше операторів. Причому в операторі switch не потрібно обов'язково загортати послідовність операторів у фігурні дужки — хоча це й не заборонено.

Зауважимо також, що в операторі switch можна використовувати власні локальні змінні, оголошення яких розташовані перед першим ключовим словом case, проте в оголошеннях немає сенсу використовувати ініціалізацію — адже вона не буде виконана (а в C++ такий код узагалі може не скомпілюватися). Загалом, якщо потрібно використовувати внутрішні змінні в блоках case оператора switch , краще використовувати складені оператори, тобто загортати списки операторів кожного блоку case у фігурні дужки (і отримувати змінну, локальну в цьому блоці).

Схема виконання оператора switch така:

  • обчислюється вираз у круглих дужках;

  • обчислене значення послідовно порівнюється з константними виразами, що йдуть за ключовими словами case;

  • якщо один із константних виразів збігається зі значенням виразу, то керування передається на оператор, позначений відповідним ключовим словом case, далі виконуються всі оператори, зокрема й позначені іншими ключовими словами case, до кінця оператора switch, якщо не трапиться оператор break;

  • якщо жоден із константних виразів не дорівнює виразу, то керування передається на оператор, позначений ключовим словом default, а в разі його відсутності керування передається на наступний після switch оператор.

Щоб не виконувалися оператори для наступних ключових слів case , наприкінці списку операторів ставлять оператор break. Оператор switch набуває вигляду:

switch ( вираз )

{ [оголошення]

case константний-вираз1: список-операторів1; break;

case константний-вираз2: список-операторів2; break;

...

[ default: [ список операторів ]]

}

У такому разі виконується рівно один зі списків операторів (якщо є default) або щонайбільше один список операторів (якщо default відсутній). Пропуск ключового слова break є типовою помилкою.

Приклади.

int i,j,k,s;

...

switch (i)
{
  case 1:case 2: j++;
  case 3: k++;
  default: s++;
}

У разі i=1 або i=2 збільшаться на 1 усі три змінні j,k,s, у разі i=3 — лише змінні k і s, інакше — лише s. Вкрай не раджу використовувати такий стиль без чіткого розуміння, навіщо це потрібно в програмі.

int i,j,k,s;

...

switch (i)
{
  case 1: case 2: j++; break;
  case 3: k++; break;
  default: s++; 
}

У разі i=1 або i=2 на 1 збільшиться лише змінна j, у разі i=3 — лише змінна k, інакше — лише s.

Наведемо приклад, у якому керівний вираз матиме символьний тип — точніше, він визначатиме символ тієї операції, яку необхідно виконати. Зауважимо, що використовувати рядок як керівний вираз не можна.

char op;

int result, x, y;

...

switch (op)

{

  case '+': result = x + y; break;

  case '-': result = x - y; break;

  case '*': result = x * y; break;

  case '/': result = x / y; break;

  default : result = 0;

}

Зауважимо, що в тілі оператора switch можна використовувати вкладені оператори switch. Оператор break при цьому перериває лише внутрішній switch.
