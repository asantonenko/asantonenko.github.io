Тест: Які значення отримають змінні після фрагмента?

Нехай виконано наступний фрагмент програми (C++):

int x = 5;
int y = 3;
double z;

z = x + 2.5;
y = x;
x = y;
y = z;

Введіть, будь ласка, значення змінних x, y та z після виконання цього фрагмента.

Підказка: у C++ при присвоєнні значення типу double змінній типу int дробова частина відкидається (не округляється).
