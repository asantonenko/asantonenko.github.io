3. Порожній оператор

Синтаксис: ;

Порожній оператор складається лише з крапки з комою. Під час виконання цього оператора нічого не відбувається. Він зазвичай використовується в таких випадках:

  • в операторах do, for, while, if у місцях, де оператор не потрібен, але за синтаксисом потрібен принаймні один оператор;

  • коли необхідно позначити фігурну дужку.

Синтаксис мови Сі вимагає, щоб після мітки обов'язково йшов оператор (у стандартах до C23 та C++23). Фігурна ж дужка оператором не є. Тому, якщо треба передати керування на фігурну дужку, необхідно використати порожній оператор.

Крім того, порожній оператор з'являється, якщо поставити зайву крапку з комою.

Приклади:

{x=1;y++;};i--;
//        ↑ порожній оператор

Тут порожній оператор з'явився, оскільки поставлено зайву крапку з комою (наприкінці складеного оператора вона не потрібна). Таких випадків появи порожнього оператора бажано уникати — для цього просто пам'ятайте, коли потрібна крапка з комою, а коли ні.

{
	if (x==0) goto exit_from_block;

	//виконуємо деякі дії

	exit_from_block: ;

}

Перед закривною фігурною дужкою стоїть порожній оператор, позначений міткою exit_from_block. Інша річ, що такий стиль (і взагалі використання оператора goto) вкрай небажаний у сучасних програмах. Використовуйте натомість оператори break, continue, return або генерацію виняткових ситуацій оператором throw. Наприклад, якщо цей фрагмент був у циклі for і потрібно пропустити (не обробляти) значення x, що дорівнює нулю, то краще використати оператор continue:

for (int x = -15; x <= 15; x++)
{
	if (x==0) continue; //пропускаємо значення, що дорівнює 0

	//виконуємо деякі дії для x від -15 до -1 і від 1 до 15
}

Нехай нам необхідно знайти в деякому масиві arr значення, що дорівнює value. 

int index = 0;
for (;index < std::size(arr) && arr[index] != value; index++);

У цьому разі всередині оператора for не знадобилося жодного оператора. Ми просто збільшували значення змінної index, поки виконано дві умови: ми перебуваємо всередині масиву (index < std::size(arr)) і елемент із заданим індексом нам не підходить (arr[index] != value). Наприкінці значення змінної index дорівнює або індексу знайденого елемента, що дорівнює value, або розміру масиву, що дорівнює std::size(arr), якщо елемент не знайдено. Оскільки змінна index потрібна після циклу, то оголосити її всередині циклу не можна. Докладніше див. опис оператора for, а також урок "Використання циклу for для контейнерів".

Загалом, порожній оператор не так часто потрібен у програмі.
